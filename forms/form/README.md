# The forms, bundled by operational model

One folder per `core-N` model, holding a copy of every Camunda Form that model's user tasks bind. Generated by `tools/bundle_forms_by_core.py` from the repository at **tag submission-2026-09-29** - the files in `forms/` beside this folder are the originals, and these are copies made for bundling and for a demonstration.

The same arrangement is documented, without the copies, in `forms/by-core.md` beside this folder.

## Checking the bundle

```bash
python tools/bundle_forms_by_core.py --check
```

It re-reads the five models, and reports any form that is missing from a folder, any extra file in one, and any copy that has drifted from the original of the same name. A copy is compared as content rather than as raw bytes, so the line endings a checkout gives a file do not read as drift: which line ending a file has is `../.gitattributes`' business, and comparing the bytes would make the check fail on a machine with `core.autocrlf` on while the committed blobs were identical.
