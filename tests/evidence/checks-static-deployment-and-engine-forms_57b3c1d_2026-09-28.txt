Why these are recorded separately
---------------------------------
`workers_java-all-three-levels_57b3c1d_2026-09-28.txt` records what the workers do. These four
checks are about the artefacts instead: that the models, the forms and the workers agree with each
other, that the diagrams follow the layout and BPMN rules, that the exported diagrams are legible,
and that a deployment of the delivered files is accepted by the engine. None of them needs a worker
to be running, and three of the four need no engine at all.

Method, and what was actually run
---------------------------------
Run from the repository root. `PYTHONIOENCODING=utf-8` is set for the export check (see the caveat
below). The engine was up and answered `GET /v2/topology` with `200` for the two checks that need it.

    python tools/verify_hprtas_bpmn_bindings.py
    python tools/verify_hprtas_bpmn_layout.py
    python tools/verify_hprtas_bpmn_export.py
    python tools/verify_hprtas_engine_forms.py

    # the deployment recipe from README.md, models then forms, one request per file
    curl -X POST http://localhost:8080/v2/deployments -F "resources=@<model>.bpmn;type=application/xml"
    curl -X POST http://localhost:8080/v2/deployments -F "resources=@<form>.form;type=application/json"

Caveat on repeating the export check
------------------------------------
`verify_hprtas_bpmn_export.py` prints its result with the words "词覆盖" in it. On a console whose
code page is cp1252 rather than UTF-8, Python raises `UnicodeEncodeError` while printing and the
script exits 1 even though every model passed. Setting `PYTHONIOENCODING=utf-8` (or `PYTHONUTF8=1`)
avoids it. `verify_hprtas_bpmn_bindings.py`, `verify_hprtas_bpmn_layout.py` and
`verify_hprtas_engine_forms.py` are unaffected. This is a portability of the check, not a result of
it: the run recorded above is the one with the encoding set.

What this run does not cover
----------------------------
* The strategic and socio-technical models are checked as documents only. They contain no
  executable process, so no instance of them can be started and none is claimed to run.
* The layout check measures geometry and the BPMN rules the lectures set out. It does not judge
  whether a diagram is a good model of the process.
* The export check reads text back with OCR. It says the labels are legible, not that they are
  correct, and a word can be missed because the recogniser misread it rather than because it was
  drawn badly.
* These checks do not exercise a task being completed by a person, so they say nothing about
  `DEF-08`; they are the evidence for the bindings that `DEF-08` leaves unproved on the Tasklist
  side.
