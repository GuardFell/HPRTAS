# Sprint Review Snapshots

> Review marks assess the increment **available at that review** - later improvements do not
> retrospectively replace those marks. Preserve a version or snapshot for each review.

```
reviews/
|-- SR1/   increment at Sprint Review 1 (before 28 September 2026)
|-- SR2/   increment at Sprint Review 2 (by 28 September 2026)
|-- SR3/   increment at Sprint Review 3 (before 22 October 2026)
`-- SR4/   increment at Sprint Review 4 (by 22 October 2026)
```

## What each snapshot contains

| Item | Why |
|---|---|
| Identified commit hash or tag | So the exact version can be reproduced |
| The BPMN model(s) as they stood | This is what "working increment" means |
| Forms and worker code as they stood | Same |
| A short `README.md` stating what worked and what did not | Distinguishes finished from unfinished work |
| Test results available at that date | Acceptance evidence |
