# Task Breakdown

> **Agile Workshop, Part 4.** Each backlog item broken into manageable tasks. A task must be
> small enough to complete **within one sprint**. Every task needs a first and second owner.

## Task size (from the workshop)

|---|---|

| "Create system" | Create Camunda Form for referral submission; Implement external worker for validation |
| "Do testing" | Test normal workflow path |
| "Make presentation" | Record feedback response |
